# Basic Routes - Routes Cơ Bản

> **Mục tiêu:** Hiểu cách tạo routes cơ bản.

## File → Route Mapping

| File | Route |
|------|-------|
| `index.vue` | `/` |
| `about.vue` | `/about` |
| `blog/index.vue` | `/blog` |
| `blog/posts.vue` | `/blog/posts` |

---

## Ví Dụ

```vue
<!-- pages/index.vue → / -->
<template>
  <h1>Home Page</h1>
</template>
```

```vue
<!-- pages/about.vue → /about -->
<template>
  <h1>About Page</h1>
</template>
```
