# Routing Exercises - Bài Tập

> **Mục tiêu:** Thực hành routing qua các bài tập.

## Bài Tập 1: Basic Routes

Tạo cấu trúc pages:
- `/` - Home
- `/about` - About
- `/contact` - Contact

## Bài Tập 2: Dynamic Routes

Tạo:
- `/blog` - Danh sách bài viết
- `/blog/[slug]` - Chi tiết bài viết

## Bài Tập 3: Nested Routes

Tạo:
- `/dashboard` - Dashboard layout
- `/dashboard/stats` - Stats page
- `/dashboard/settings` - Settings page

## Bài Tập 4: Protected Routes

Thêm auth middleware cho `/dashboard`.
