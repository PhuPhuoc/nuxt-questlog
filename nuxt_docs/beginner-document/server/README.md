## 1. Giới thiệu

Server Routes cho phép tạo API endpoints trực tiếp trong Nuxt.

**Lợi ích:**
- Cùng codebase với frontend
- TypeScript support
- H3 framework mạnh mẽ
- SSR integration

Tạo API endpoints cho blog:

- POST /api/posts - Tạo bài viết
- GET /api/posts/[id] - Chi tiết bài viết
