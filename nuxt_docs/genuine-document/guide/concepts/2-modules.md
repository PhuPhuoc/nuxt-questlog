# Modules

## Giới Thiệu

Modules là các functions chạy tuần tự khi khởi động Nuxt ở development mode sử dụng `nuxt dev` hoặc build project cho production với `nuxt build`.

Với modules, bạn có thể encapsulate, test đúng cách, và chia sẻ các giải pháp tùy chỉnh như npm packages mà không cần thêm boilerplate không cần thiết vào project.
